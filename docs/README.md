# Документы

Два раздела для двух аудиторий.

## `dev/` — разработка

Для тех, кто пишет код платформы: людей и ИИ-агентов. Хранится в репозитории вместе с кодом и меняется в тех же коммитах.

- [ARCHITECTURE.md](dev/ARCHITECTURE.md) — как устроена платформа и почему так.
- [ROADMAP.md](dev/ROADMAP.md) — этапы с отметками.
- [CONTENT-FORMAT.md](dev/CONTENT-FORMAT.md) — формат курса: узлы, блоки, вопросы.
- [LESSON-WORKFLOW.md](dev/LESSON-WORKFLOW.md) — как делается урок: порядок работы, проверка, грабли.
- [decisions/](dev/decisions/) — принятые решения (ADR), по одному на файл.
- `dev/_local/` — личные черновики. Папка в `.gitignore` и в репозиторий не попадает.

## `guides/` — для публики

Для тех, кто пользуется платформой: учеников, авторов курсов, тех, кто поднимает сервис у себя. Пишутся простым языком, без устройства кода.

- [authoring.md](guides/authoring.md) — как написать хороший урок.

Гайды для учеников и по установке появятся вместе с соответствующими этапами плана.
