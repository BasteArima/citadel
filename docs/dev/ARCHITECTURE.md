# Архитектура

Документ описывает цель. Что уже сделано — в [ROADMAP.md](ROADMAP.md).

## Главный принцип

**Курс — это данные, сайт — движок.** Урок — не свёрстанная страница, а дерево узлов из типизированных блоков: абзац, код, «предскажи и запусти», анимация, вопрос. Один движок показывает любой курс. Редактор админа и ИИ-агенты правят одни и те же данные: первый через интерфейс, вторые через API.

## Кто пользуется

| Роль | Что делает |
|---|---|
| Ученик | проходит курсы, повторяет, видит прогресс и свою цепь |
| Админ | создаёт и правит курсы, публикует, принимает правки агентов, раздаёт доступы |
| Агент | читает курсы, предлагает правки через API или MCP; публиковать не может |

## Части системы

```
браузер ──► Go-сервер (одна программа)
             ├── раздаёт фронтенд: движок + редактор
             ├── API: курсы, прогресс, правки, доступы
             ├── MCP-сервер для агентов (поверх того же API)
             └── SQLite в Docker-томе
```

- **Сервер** — одна программа на Go: статика, API, проверка контента, миграции. Решение: [0002](decisions/0002-go-sqlite-single-binary.md).
- **Хранилище** — SQLite: курсы с версиями, пользователи, прогресс, правки. Бэкап — копия одного файла. Если пользователей станет много — Postgres.
- **Фронтенд** — движок нынешнего Go-курса, отделённый от контента. Нативные ES-модули, без сборщика на старте. Один и тот же код рисует урок ученику и превью в редакторе.
- **Деплой** — Docker Compose на домашнем сервере владельца, домен `citadel.baste.ru` через Nginx Proxy Manager.

## Модель контента

Подробно — [CONTENT-FORMAT.md](CONTENT-FORMAT.md).

- **Курс** — паспорт (название, металл звена, версия инструмента, правила прохождения, подписи узлов) и дерево узлов.
- **Узел** — вложенный элемент дерева с типом: раздел, урок, часть, страница. Глубина не фиксирована, подписи настраиваются в курсе: «Урок», «Глава», «Разбор».
- **Блок** — содержимое узла. Тип блока — подключаемый модуль (ниже).
- **Словарь** курса — термины. Ссылки на термины и на другие узлы проверяются при сохранении.

### Версии и публикация

Каждое сохранение создаёт новую версию. Ученики видят только опубликованную версию, публикует админ. Правки агентов попадают в очередь: админ видит разницу и принимает или отклоняет. Решение: [0003](decisions/0003-agents-edit-via-drafts.md).

## Гибкость

Большинство курсов пойдут в общем формате, но курс должен уметь отличаться, не трогая движок. Решение: [0004](decisions/0004-extensibility.md).

1. **Блоки — модули.** Модуль блока — это схема данных, отрисовка, форма в редакторе, текст для озвучки и правило «что считается выполненным». Новый тип блока — новый модуль. Неизвестный тип показывается заглушкой и не ломает страницу.
2. **Дерево вместо фиксированных уровней.** Курс сам решает, из чего состоит.
3. **Свои страницы курса.** Любая страница из блоков в меню курса: «Шпаргалка», «Инструменты». Справочник (словарь, конспект, контрольная) — тоже такие страницы, включаются для каждого курса отдельно.
4. **Правила прохождения — настройка.** Для узла задаётся, что значит «пройдено»: ответил на вопросы, дочитал, выполнил задание, отметил вручную. Интервалы повторений — в паспорте курса.
5. **Свой код — в песочнице.** Интерактивный компонент курса (тренажёр консоли, визуализатор планировщика) работает в iframe на отдельном адресе и общается с движком только сообщениями: «решено», «шаг N». До прогресса, токенов и админки он не дотягивается.
6. **Версия формата.** У курса есть версия схемы. Изменение формата блока сопровождается миграцией, которую сервер применяет сам.
7. **Схема — через API.** Агент запрашивает актуальную схему блоков и всегда знает, что сейчас поддерживается.

## Прогресс и повторения

Прогресс хранится на сервере и в браузере: офлайн всё работает, при подключении синхронизируется. Слияние — по каждому узлу и вопросу, более свежая отметка побеждает, а не «последний перезаписал всё». Повторения — одна очередь по всем курсам.

Вход — по имени и коду доступа сервиса. Полноценные аккаунты — когда появятся люди кроме владельца.

## Страницы

- **Ученик:** каталог курсов плитками со статусами и общим «Повторить сегодня»; страница курса; узел (урок, часть); справочник курса; проекты: плитки, страница проекта, шаг с ТЗ ([0016](decisions/0016-projects.md)); повторения; профиль с цепью.
- **Админ:** курсы; редактор узла с живым превью; вопросы и словарь; история версий и разница; очередь правок агентов; пользователи и токены.
