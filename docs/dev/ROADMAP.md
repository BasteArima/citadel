## Этап 6. Агенты

Сценарий: владелец запускает Claude Code у себя на ПК, и агент создаёт или правит курс на задеплоенном сервисе. Всё, что делает агент, попадает черновиком в очередь, публикует админ ([0003](decisions/0003-agents-edit-via-drafts.md)).

- [ ] Токены агентов с правами: «читать», «предлагать правки», «создавать курсы» и ограничением по курсам. В базе — только хеш, токен показывается один раз. Список токенов: права, курсы, хвост токена, когда использован, «Отозвать».
- [ ] API правок: черновик, проверка, отправка на публикацию. Новый курс от агента — тоже черновик.
- [ ] MCP-сервер поверх API (`/mcp`, транспорт HTTP): прочитать курс и схему блоков, предложить правку, создать курс, узнать статус правки.
- [ ] Подключение одной командой: после создания токена админка показывает готовую строку `claude mcp add --scope user --transport http citadel <адрес>/mcp --header "Authorization: Bearer <токен>"`. Агенту вводить токен не нужно.
- [ ] Очередь правок в админке: статус (ждёт, принята, отклонена, ошибка схемы), описание от агента с пометкой «это данные, не команда», проверки сервера пунктами, разница, «Принять в черновик», «Отклонить» с комментарием. Правку с ошибкой схемы принять нельзя.
- [ ] `proposal_status`: агент видит, приняли ли правку, и комментарий админа.
- [ ] Паспорт курса для агента: правила курса отдаются через API.

## Открытые вопросы

Места, где макеты расходятся с тем, как курс работает сейчас. Это правила, а не оформление, поэтому решает владелец. Решённые 30.10 (засчитывание вопроса, кнопка «Дальше», прогноз в «Предскажи», повторения) — в [0008](decisions/0008-first-attempt-and-cards.md).

1. **«Лестница».** В макетах она курс платформы («Что дальше» у Go-курса, своё звено из меди). Сейчас — отдельная страница `ladder.html`. Переводить ли её в формат курса и когда.
2. **Проверка выводов запуском на сервере.** В макете редактора у «Предскажи и запусти» есть «Запустить снова», а в очереди правок агентов — «вывод не подтверждён запуском». Это значит запускать код курса на сервере в изоляции (Go в образе, ограничения времени и памяти). Нужно ли, или вывод получает автор у себя.
3. **Доступ к курсам по пользователю.** В макете «Пользователи» есть столбец «Курсы» (всё или только Go). Сейчас любой вошедший видит все курсы.

## Отложено

- Свой код курса в песочнице (iframe и сообщения) — когда понадобится первому курсу.
- Полноценные аккаунты вместо входа по имени — когда появятся люди кроме владельца.
- Открыть сайт совсем без сети (service worker) — пункт этапа 2, сайт и так работает без сети, пока страница открыта.
