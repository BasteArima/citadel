## Этап 6. Агенты — 30.10 ✅

- [x] Подключение одной командой: после создания токена админка показывает готовую строку `claude mcp add --scope user --transport http citadel <адрес>/mcp --header "Authorization: Bearer <токен>"`. Агенту вводить токен не нужно.
