# 0014. Голос озвучки — Светлана через edge-tts

Дата: 2026-10-31 · Статус: принято

## Контекст

Озвучку курсов делаем заранее записанными файлами (`docs/dev/AUDIO.md`). 31.10 владелец послушал примеры восьми голосов на тексте урока: Microsoft (Светлана, Дмитрий, многоязычные Andrew и Ava) и локальный Piper (Дмитрий, Ирина, Денис, Руслан). Понравилась Светлана. Тот же голос доступен двумя путями: бесплатно через `edge-tts` и официально через Azure AI Speech.

## Решение

- Голос — `ru-RU-SvetlanaNeural`.
- Получаем через `edge-tts`, бесплатно.
- Скрипт записи делается так, чтобы движок синтеза был одной настройкой: имя голоса у `edge-tts` и Azure одно и то же, переход на Azure — замена способа запроса, а не переделка курса.
- Записанные файлы хранятся у нас (том данных сервиса) и не зависят от доступности синтеза: если `edge-tts` перестанет работать, готовая озвучка останется, переозвучивать придётся только новые и изменённые части.

## Почему не иначе

- **Azure.** Тот же голос и легальный доступ, весь Go-курс почти укладывается в бесплатные 0,5 млн символов в месяц. Владелец выбрал бесплатный путь без аккаунта и ключа; Azure — запасной путь с тем же звуком.
- **Yandex SpeechKit.** Светланы там нет; около 275 ₽ за Go-курс в API v3. Не нужен, пока устраивает голос Microsoft.
- **Piper.** Бесплатно и без сети, но звучит заметно роботизированнее.

## Последствия

- `edge-tts` — неофициальный доступ к сервису «Прочитать вслух» браузера Edge: Microsoft может его закрыть или ограничить. Тогда — переход на Azure с тем же голосом (нужен ключ в `.env`).
- Запросы иногда зависают: скрипт записи делает таймаут и до трёх повторов.
- Текст курсов уходит в сервис Microsoft — это публичный учебный текст, секретов в нём нет.
