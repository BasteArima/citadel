# 0006. Движок на модулях блоков, прогресс по id вопросов

Дата: 2026-10-29 · Статус: принято

## Контекст

Прежний движок (`app.js`) читал модель v0 через временный переходник ([0005](0005-v0-converter-and-adapter.md)), рисовал блоки одним большим `if` по ключам, хранил решённые вопросы по номеру в списке `test`, а тексты главной и таблицу практикума Go-курса держал прямо в коде. Для платформы из многих курсов это не годится: новый тип блока требует правки движка, прогресс ломается от перестановки вопросов, второй курс получил бы чужие тексты.

## Решение

- Движок — ES-модули без сборщика в `web/static/engine/`. Курс приходит из API в v1 и читается напрямую, переходник удалён.
- Тип блока — модуль `{ type, render, speak, questions }` в `blocks/`: отрисовка, что читать озвучке, от каких вопросов зависит выполнение части. Неизвестный тип — заглушка.
- У каждого вопроса — `id`, уникальный в курсе. Прогресс хранится как `{ id вопроса: 1 }`. Конвертер даёт `урок.qN` вопросу `test[N-1]` и `урок.hN` вопросу `hands.check[N-1]`, так что прогресс из старого курса переносится без потерь.
- Тексты, которые были только про Go-курс, переехали в данные: `about` и `howto` в паспорте, «Практикум» — страница курса (узел `page`). У Go-курса их источник — `legacy/go-course/data/platform.js`.
- Настройки (тема, скорость озвучки) — общие для всех курсов (`citadel-ui`), прогресс — по курсу (`citadel-progress:<id>`).

## Почему не иначе

- **Оставить прежний `app.js` и переходник.** Работает, но модель v0 тогда живёт вечно, а модули блоков некуда вставить.
- **Прогресс по номеру вопроса.** Проще, но любая вставка вопроса сдвигает чужие отметки, а синхронизация (этап 2) сливает прогресс именно по вопросам.
- **Id из текста вопроса (хеш).** Не требует нумерации, но правка опечатки в вопросе сбрасывает его прогресс.

## Последствия

- Проверка курса требует `id` у каждого вопроса и следит, чтобы id не повторялись.
- Страница движка совпадает с прежней на всех маршрутах уроков и словаря. На главной карточка практикума теперь называется по странице («Практикум»).
- Прогресс, отмеченный в прежнем курсе (`gocourse-v1`), сам не переносится: другой адрес — другое хранилище. Импорт — этап 2, по правилу `урок.qN = test[N-1]`.
