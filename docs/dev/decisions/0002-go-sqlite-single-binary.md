# 0002. Одна программа на Go и SQLite

Дата: 2026-10-29 · Статус: принято

## Контекст

Сервис живёт на домашнем сервере владельца, пользователей единицы, поднимается через Docker. Владелец готовится к собесам на Go-бэкендера.

## Решение

Бэкенд — одна программа на Go: раздаёт фронтенд, API и MCP. Данные — SQLite в Docker-томе. Фронтенд — нативные ES-модули без сборщика, пока это не мешает.

## Почему не иначе

- **Postgres отдельным контейнером.** Для единиц пользователей это лишний сервис, лишние бэкапы и миграции. Переход возможен позже: доступ к данным идёт через слой хранилища.
- **Node или Python на бэкенде.** Работают не хуже, но Go — язык, который владелец изучает, и код сервиса — живой пример для него.
- **SPA-фреймворк и сборка.** Нынешний движок на ванильном JS уже работает. Сборщик добавим, если без него станет тяжело (например, ради TypeScript в редакторе).

## Последствия

- Бэкап — копия файла базы. Для этого нужен режим WAL и копирование через SQLite API, а не простым `cp` на ходу.
- Одна запись в базу за раз — для этого масштаба не ограничение.
