# 0011. Второй курс — PostgreSQL: что в движке было про Go

Дата: 2026-10-30 · Статус: принято

## Контекст

Этап 7 проверяет, что платформа общая, а не обёртка вокруг Go-курса. Второй курс — «PostgreSQL для бэкендера»: раздел про индексы и планы запросов (первый урок написан, остальные в плане) и раздел про транзакции (в плане). Все выводы `psql` в уроке получены запуском на PostgreSQL 18.6 в Docker (`postgres:18-alpine`).

## Решение

Что пришлось поменять, потому что движок знал про Go:

- **Файл и команда по умолчанию.** «Предскажи и запусти» подставлял `main.go` и `go run .`, блок кода — название инструмента. Теперь это поля паспорта `tool.file` и `tool.cmd` (у Go-курса `main.go` и `go run .`, у Postgres `query.sql` и `psql -f query.sql`); редактор берёт их же для новых блоков и показывает в подписи поля.
- **Версия у «Предскажи».** Поле `go` (версия, если вывод получен не на версии из паспорта) переименовано в `ver`: в контенте оно не использовалось, миграция не нужна.
- **Боковая врезка.** У врезки вида `cs` подпись по умолчанию была «Если ты из C#». Теперь она из `labels.cs` паспорта; у Postgres — «Если ты из C# и EF Core». Вид `cs` остаётся: это «свёрнутая врезка сбоку от основной линии», а не только про C#.
- **Перенос прогресса из прежнего движка** показывался на странице любого курса. Теперь — только у курса с `legacy: "v0"` (его ставит конвертер Go-курса).

Что менять не пришлось: дерево узлов, части урока, блоки (таблицы, анимация, задание руками, вопросы), засчитывание, карточки, справочник, поиск, админка и API агента. «Скажи на собесе» оставлен общим: курсы платформы готовят к собеседованиям.

## Почему не иначе

- **Подсветка синтаксиса по языку** не понадобилась: в движке её нет, код показывается моноширинным текстом одинаково для Go и SQL.
- **Отдельный тип блока для SQL-запроса с результатом** не нужен: «Предскажи и запусти» с `psql`-выводом читается так же, как с выводом программы.
- **Хранить скрипт-генератор курса в репозитории** — нет: источник курса — версии в базе ([0009](0009-database-is-the-source.md)), `content/postgres/course.json` — начальная загрузка.

## Последствия

- Новый курс задаёт в паспорте `tool.file`, `tool.cmd` и, если нужна боковая врезка, `labels.cs`.
- Время «Сделай руками» движок оценивает в 3 минуты на шаг, и у практики из семи коротких шагов выходило 21 мин. Автор может указать время сам — поле `min` у блока `hands` (этап 8).
