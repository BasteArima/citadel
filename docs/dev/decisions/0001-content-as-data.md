# 0001. Курс — данные, сайт — движок

Дата: 2026-10-29 · Статус: принято

## Контекст

Go-курс вырос из одного сайта. Хотим много курсов, правки из редактора и от ИИ-агентов, в том числе на задеплоенном сервисе.

## Решение

Курс хранится как структурированные данные: дерево узлов из типизированных блоков. Сайт — движок, который рисует любой курс. Редактор и агенты правят данные, а не HTML.

## Почему не иначе

- **Курс как свёрстанные страницы или Markdown.** Агенту легко писать, но нельзя проверить структуру: что у вопроса есть правильный ответ, что термин есть в словаре, что анимация собирается. Интерактивные блоки в Markdown превращаются во вставки, которые всё равно надо разбирать.
- **Курс как файлы в git, правки — через PR.** Хорошо для разработчика, неудобно для правок на живом сервисе и для админа без git. Экспорт в файлы остаётся для бэкапа и переноса.

## Последствия

- Нужна схема формата и проверка на сервере.
- Нужен редактор с формами под блоки — писать текст в JSON руками неудобно.
- Любое изменение формата — через миграцию (решение 0004).
