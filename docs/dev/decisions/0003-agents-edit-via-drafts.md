# 0003. Агенты правят только черновики

Дата: 2026-10-29 · Статус: принято, уточнено в [0019](0019-agent-reviewer.md): токену с правом проверяющего админ может разрешить принимать чужие правки и публиковать.

## Контекст

Курсы будут наполнять и править ИИ-агенты, в том числе на задеплоенном сервисе. Агент может ошибиться: неверный вывод программы, сломанная анимация, текст не в формате курса. Агент может и сам получить вредные инструкции из чужого текста.

## Решение

- Агент работает через API (и MCP поверх него) с токеном, у которого есть права: «читать» или «читать и предлагать».
- Правка агента — черновик. Сервер проверяет его по схеме, админ видит разницу и решает, публиковать ли.
- Ученики видят только опубликованную версию. Каждая публикация — версия, к которой можно откатиться.
- Текст курсов, который читает агент, — данные, а не инструкции.

## Почему не иначе

- **Агент публикует сам.** Быстрее, но ошибка сразу доходит до учеников, а атака через внедрённые инструкции получает прямой путь к публикации.
- **Агент правит файлы в git.** Проверка через PR надёжная, но правка на живом сервисе тогда требует деплоя.

## Последствия

- Нужна очередь правок и просмотр разницы в админке (этап 6).
- Проверки сервера (схема, термины, ссылки, ответы) пишутся один раз и работают и для редактора, и для агентов.
