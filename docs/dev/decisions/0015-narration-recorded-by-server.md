# 0015. Озвучку записывает сервер, синтез — программа edge-tts

Дата: 2026-10-31 · Статус: принято. Уточняет [0014](0014-voice-svetlana-edge-tts.md) и план в `docs/dev/AUDIO.md`.

## Контекст

Голос и путь выбраны в 0014: Светлана через `edge-tts`. В `AUDIO.md` планировалось два варианта: скрипт записи на Python в `tools/tts/` или протокол `edge-tts`, переписанный на Go. Владелец хочет делать записи прямо на сервере, кнопкой в админке.

Когда стали переносить протокол на Go, выяснилось: сервис «Прочитать вслух» требует токен `Sec-MS-GEC`. В `edge-tts` 7.3 он считается изменённым SHA-256 с подменёнными константами и ещё одной хеш-функцией, а версия Edge зашита в константы. Microsoft меняет это вместе с версиями браузера, и пакет `edge-tts` выпускает обновления вслед за ней.

## Решение

- **Записи делает сам Citadel**, фоновой задачей по кнопке в админке («Озвучка» курса). Текст частей собирает Go (`internal/speech`): главы, словарь произношения, `hash`. Склейка MP3 и длительности глав — тоже Go. Файлы — в `<data>/audio/<курс>/`, что из чего сделано — в таблице `audio` базы.
- **Синтез — внешняя программа `edge-tts`** (Python-пакет, версия закреплена). Citadel вызывает её на каждую главу: `edge-tts --voice … --file … --write-media …`, с таймаутом и тремя попытками. В Docker-образе пакет ставится в своё окружение `/opt/edge-tts`. Локально путь задаёт `CITADEL_TTS` (окружение `.tts/` в корне репозитория, оно в `.gitignore`).
- Синтез — интерфейс `speech.Synth`. Переход на Azure или другой сервис — новая реализация интерфейса, а не переделка курса.
- Если сервис недоступен напрямую, `CITADEL_TTS_PROXY` передаёт программе `--proxy`. В логи прокси не попадает.

## Почему не иначе

- **Протокол на Go.** Пришлось бы повторять обфусцированный токен и следить за каждым его изменением самим. С пакетом обновление — смена версии в Dockerfile.
- **Отдельный сервис синтеза в compose.** Ещё один контейнер и сеть ради одной команды. Образ с Python вырос со ~85 до 138 МБ — это приемлемо.
- **Скрипт на ноутбуке владельца.** Тогда записи пришлось бы переносить на сервер руками, а кнопки «Озвучить изменённое» не было бы.

## Последствия

- Серверу нужен выход в интернет к `speech.platform.bing.com`. 31.10 из сети владельца этот хост то отвечал, то зависал на TLS (TCP открывается, ответа нет), хотя `microsoft.com` открывался сразу. Если на домашнем сервере так же — нужен прокси (`CITADEL_TTS_PROXY`).
- Python в образе — только для синтеза. Код курсов в Citadel по-прежнему не выполняется: для него есть исполнитель ([0013](0013-running-course-code.md)).
- Обновить `edge-tts`: поменять версию в `Dockerfile` и в инструкции для локального окружения (`.env.example`), пересобрать образ.
