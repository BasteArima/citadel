# 0024. Направления курсов в каталоге

Дата: 2026-11-16 · Статус: принято

## Контекст

При росте числа курсов разных авторов длинный список на главной становится неудобным. Нужна общая группировка, которая учитывает доступ ученика и не меняет переносимый формат курса.

## Решение

Хранить направления в таблице `directions`: постоянный id, название и позиция. Курс или проект получает одно необязательное направление в `courses.direction`. Внешний ключ с `ON DELETE SET NULL` оставляет курсы без направления при его удалении. Порядок меняется перемещением на позицию с последовательным сдвигом соседей.

Общий список создаёт, переименовывает и упорядочивает админ. Автор выбирает направление только для своих курсов и проектов. Названия уникальны без учёта регистра, включая русский алфавит: проверка `strings.EqualFold` выполняется внутри транзакции записи, поскольку SQLite `NOCASE` учитывает только ASCII. Все изменения проходят через журнал действий.

Главная показывает текущее обучение и каталог по непустым для ученика направлениям. Проекты живут на отдельной странице; на главной остаётся только текущий шаг начатого проекта. Метаданные направления и имени владельца читаются отдельно от версий курса.

## Почему не иначе

Направление хранится в базе, как доступ и владелец ([0012](0012-course-access.md), [0023](0023-course-authors.md)): это устройство конкретного каталога платформы, а не содержание учебного материала. Импорт JSON и новые версии сохраняют назначение; экспорт и API агента не получают новых полей формата курса.

Один уровень без подкатегорий даёт понятный выбор и простую навигацию. Пока нет данных, оправдывающих дерево категорий или несколько направлений у одного курса.

Авторы не создают элементы общего списка: иначе появятся дубликаты вроде «Программирование» и «программирование» и близкие по смыслу группы. Админ поддерживает единые названия; автору остаётся выбор из них.

## Последствия

Потребовалась новая миграция, отдельные маршруты управления и проверки прав. Существующие курсы после миграции находятся в группе «Без направления». Пустые направления в ученическом каталоге скрыты, но остаются доступными администратору и автору для назначения. Изменение названия или удаление направления не создаёт версий курса.
