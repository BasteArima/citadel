Набор методов: где прячется ловушка

У каждого типа есть набор методов — список методов, которые можно вызвать у его значений. Набор *T включает методы с ресивером T и *T, а набор T — только с ресивером T.

type Circle struct{ R float64 }

func (c *Circle) Area() float64 { return 3.14 * c.R * c.R }

var s Shape = Circle{R: 2} // ошибка: method Area has pointer receiver
Если ты из C#

В C# класс обязан объявить интерфейс. В Go тип подходит, если у него есть все методы, — объявлять ничего не нужно.

Проверь себя · вопрос 1 из 2
У Circle метод func (c *Circle) Area(). Что скомпилируется?
var s Shape = Circle{R: 1}
var s Shape = &Circle{R: 1}
Оба варианта
Верно. В набор методов Circle метод с ресивером *Circle не входит, в набор *Circle — входит.
